Transformation

The transformations provided here focus on intensity normalization for downstream analysis. In JuChrom, the centered log-ratio (CLR) transform converts strictly positive, compositional data from the simplex into log-ratio coordinates in Euclidean space, which many multivariate projection methods assume (for example PCA, PLS, and CPPLS-DA). Whitening rescales values by their variances to make the data homoscedastic to first order, so features with larger uncertainty do not dominate distances, correlations, or model fits. Apply these steps when downstream analyses assume or benefit from Euclidean geometry or homoscedasticity (for example PCA, PLS, or CPPLS-DA).

Use replacecensored before CLR when a variance-carrying mass-scan matrix contains non-positive or below-limit intensities. It replaces censored values by positive below-limit estimates and updates their variances on the same final analysis grid.

ticnormalize scales a mass-scan matrix by the sum of positive total-ion-chromatogram (TIC) values. For a VarianceMassScanMatrix, variances are propagated as fixed scaling (V ./ scale^2). The normalization denominator is treated as the observed scaling factor; uncertainty in that denominator is not propagated because it would introduce covariances between all normalized cells, while VarianceMassScanMatrix stores only per-cell variances.

CLR is invariant to this global TIC scaling. For strictly positive data, clr(ticnormalize(vmsm)) gives the same CLR intensities and propagated CLR variances as clr(vmsm). If the matrix contains zeros or negative values and you want CLR output, first replace censored values:

clr(ticnormalize(replacecensored(vmsm)))

This gives the same CLR result as clr(replacecensored(vmsm)), with the TIC-normalized intermediate available if you need it for inspection or other analysis.

Example

using JuChrom

msm = MassScanMatrix(
    [1.0, 2.0]u"s",
    [100.0, 101.0],
    [1.0 2.0; 4.0 8.0]u"pA",
)
vmsm = VarianceMassScanMatrix(msm, [0.01 0.04; 0.16 0.64] .* u"pA"^2)

vmsm_clr = clr(vmsm)
vmsm_whitened = whiten(vmsm_clr)

whiten returns dimensionless intensities and variances. By default it infers a standard-deviation floor from the positive propagated standard deviations (sigmafloor = :auto, floorquantile = 0.05). Pass an explicit bare number for dimensionless transformed data, for example whiten(vmsm_clr; sigmafloor=0.01). Pass a unitful floor for physical intensity data, for example whiten(vmsm; sigmafloor=0.1u"pA"); the intensities and variances are converted to that unit before units are stripped.

Intensity units and dwell normalization

Use withintensityunit when the numeric intensity values already have a known unit that is absent from the container. It attaches that unit without rescaling values. For example, withintensityunit(msm, u"s^-1") labels an already normalized rate.

Use dwellnormalize when stored intensity is proportional to the duration of measurement. Having no intensity unit does not by itself establish this relationship. The function requires an explicit unitful duration, or explicit m/z-to-duration pairs; acquisition-method interpretation and estimation of dwell are separate operations.

using JuChrom

msm = MassScanMatrix(
    [1.0, 2.0]u"s",
    [100.0, 200.0, 300.0],
    [10.0 20.0 30.0; 40.0 50.0 60.0],
)

# Known dwell duration for each ion; pair order need not follow column order.
dwell = (300 => 500u"ms", 100 => 0.2u"s", 200 => 300u"ms")
normalized = dwellnormalize(msm, dwell)
rawintensities(normalized)
2×3 Matrix{Float64}:
  50.0   66.6667   60.0
 200.0  166.667   120.0

Tuples and vectors of pairs, and dictionaries, are accepted. Every matrix m/z value needs a duration, including columns containing only zeros. Additional ions are allowed, so the same acquisition specification can be reused after selecting fewer columns. Duplicate m/z keys and missing durations are errors. All entries are validated, including ions absent from the matrix. Durations must be finite, positive quantities with time units.

Keys follow the same unit conventions as mscanmatrix: plain keys use the matrix's m/z unit, if any; unitful keys are converted to that unit before exact matching. Mixed plain/unitful keys, incompatible units, and unitful keys for a unitless m/z axis are rejected. Keys must be finite and positive. Compatible units may differ between keys; duplicates are checked after conversion. There is no rounding or approximate matching.

For a known duration shared by all columns, use a scalar. This form makes no assumption about whether acquisition was sequential or simultaneous:

shared = dwellnormalize(msm, 500u"ms")
rawintensities(shared)
2×3 Matrix{Float64}:
 20.0   40.0   60.0
 80.0  100.0  120.0

All durations are converted to seconds. Results always have intensity unit s^-1, independently of input time units, pair order, or additional ions. Input intensities must have no attached unit. Both dense and sparse matrices are supported; storage is preserved. Axes, MS level, and metadata are copied.

intensityunit(normalized)
s^-1

For VarianceMassScanMatrix, the same API divides variances by the squared dwell durations, yielding variance unit s^-2:

vmsm = VarianceMassScanMatrix(msm, [1.0 4.0 9.0; 16.0 25.0 36.0])
normalized_variances = dwellnormalize(vmsm, Dict(dwell))
rawvariances(normalized_variances)
2×3 Matrix{Float64}:
  25.0   44.4444   36.0
 400.0  277.778   144.0

There is no argument-free inference, positional duration-vector form, or acquisition keyword. Neither recorded ions nor adjacent retention spacing determines the normalization. Durations are not checked against retention spacing: explicit dwell works for single scans, selected scans, and transformed or unitless retention coordinates. Establishing whether a duration correctly describes the acquisition is the caller's responsibility.

JuChrom.clr — Function
clr(vmsm::AbstractVarianceMassScanMatrix) -> VarianceMassScanMatrix

Apply the centered log-ratio (CLR) transformation to the intensity matrix of a variance mass scan matrix and propagate the associated per-cell variances.

The input intensities must be strictly positive. clr does not replace zeros or negative values; use replacecensored before clr when censored or baseline-corrected data contain non-positive cells.

The returned VarianceMassScanMatrix keeps the retention axis, m/z axis, level, metadata, and extras of the input. CLR values are log-ratio coordinates, so both intensityunit and varianceunit of the returned object are nothing.

Variance propagation uses the delta-method variance of log(x) followed by the finite CLR centering correction: sigma2_clr[i] = sigma2_log[i] * (1 - 2/N) + sum(sigma2_log) / N^2, where sigma2_log[i] = variance[i] / intensity[i]^2 and N is the number of cells.

Throws

  • DomainError: if any intensity is zero or negative.
  • DimensionMismatch: if the variance matrix shape does not match the intensity matrix.

JuChrom.dwellnormalize — Function
dwellnormalize(msm::Union{MassScanMatrix, VarianceMassScanMatrix}, dwell)

Return a copy with intensities divided by explicitly supplied dwell durations.

dwell is either a single unitful duration shared by every m/z column, or a tuple/vector of mz => duration pairs or a dictionary associating m/z values with unitful durations. Every duration must be real-valued, finite, positive, and have units of time. Durations are converted to seconds; output intensities have unit s^-1, independently of the units or ordering of the specification. A shared duration does not imply simultaneous acquisition.

For m/z-specific durations, every matrix column, including zero-filled columns, needs an entry. Additional ions are allowed. Matching is exact, without rounding or tolerance. Keys must be finite and positive, and either all plain real numbers or all real-valued quantities. Plain keys use the matrix's m/z unit, if any. Unitful keys are converted to that unit before matching and require a unitful matrix m/z axis. Compatible key units may differ. Duplicate keys are rejected after unit conversion, including duplicates for ions absent from the matrix. All entries, including additional ions, are validated.

The input intensity unit must be absent, and its values must represent signal proportional to dwell duration. If the stored values already represent a rate, use withintensityunit to attach its known unit without rescaling. This function does not infer dwell from recorded ions or retention spacing, and does not check durations against scan intervals. Single scans and transformed or unitless retention axes work.

For VarianceMassScanMatrix, variances are divided by squared dwell durations and have unit s^-2. Dense/sparse storage is preserved. Axes, MS level, and metadata are copied.

Throws ArgumentError for invalid durations or keys, duplicate or missing keys, malformed pair collections, or an input with an intensity unit. Positional duration vectors, unitless durations, automatic inference, and the acquisition keyword are not supported.

See also intensityunit, varianceunit, withintensityunit.

Examples

julia> msm = MassScanMatrix([1.0, 2.0]u"s", [57, 71], [10.0 20.0; 30.0 40.0]);

julia> shared = dwellnormalize(msm, 10u"ms");

julia> rawintensities(shared) == [1000 2000; 3000 4000]
true

julia> normalized = dwellnormalize(msm, (71 => 20u"ms", 57 => 0.01u"s"));

julia> rawintensities(normalized) == [1000 1000; 3000 2000]
true

julia> intensityunit(normalized) == u"s^-1"
true

julia> rates = dwellnormalize(msm, Dict(57 => 10u"ms", 71 => 20u"ms", 85 => 5u"ms"));

julia> rawintensities(rates) == rawintensities(normalized)
true

julia> vmsm = VarianceMassScanMatrix(msm, [1.0 4.0; 9.0 16.0]);

julia> normalizedvar = dwellnormalize(vmsm, [57 => 10u"ms", 71 => 20u"ms"]);

julia> rawvariances(normalizedvar) == [10000 10000; 90000 40000]
true

julia> varianceunit(normalizedvar) == u"s^-2"
true

JuChrom.replacecensored — Function
replacecensored(vmsm::AbstractVarianceMassScanMatrix; kwargs...) -> VarianceMassScanMatrix
replacecensored(vmsm::AbstractVarianceMassScanMatrix; returninfo=true, kwargs...) ->
    (VarianceMassScanMatrix, CensoredReplacementInfo)

Replace non-positive and below-limit intensities in vmsm by positive censored-value estimates and update their variances.

For each intensity cell x[i, j] with variance v[i, j], a reliability limit is computed as L[i, j] = max(floor[j], k * sqrt(v[i, j])). Values with x[i, j] <= L[i, j] are treated as censored and replaced by L[i, j] / 2. Their variances are replaced by max(v[i, j], L[i, j]^2 / 12), corresponding to the uncertainty of an unknown value in [0, L[i, j]] under a uniform censoring model. Values above the limit are copied unchanged.

By default, floor=:column_quantile, so floor[j] is the q quantile of positive intensities in m/z column j. Columns with fewer than minpositives positive values use the global positive-intensity quantile. Use floor=:global_quantile for one shared floor, a scalar for a fixed floor, or a vector with one floor per m/z column.

Keyword arguments:

  • k::Real=3.0: multiplier for the propagated standard deviation.
  • q::Real=0.01: positive-intensity quantile used for empirical floors.
  • floor=:column_quantile: floor rule, scalar floor, or per-column floor vector.
  • minpositives::Integer=10: minimum positive values required for a column floor.
  • returninfo::Bool=false: return a CensoredReplacementInfo when true.

The returned matrix preserves retention, m/z, units, metadata, extras, and variance units.

JuChrom.ticnormalize — Function
ticnormalize(msm::MassScanMatrix) -> MassScanMatrix
ticnormalize(vmsm::AbstractVarianceMassScanMatrix) -> VarianceMassScanMatrix

Normalize a mass-scan matrix by the sum of positive total-ion-chromatogram (TIC) values.

For an intensity matrix X, the TIC is the row-wise sum of intensities. ticnormalize computes

tic = vec(sum(X; dims=2))
scale = sum(t for t in tic if t > 0)

and returns intensities X ./ scale. All cells are scaled, including zero and negative cells, but only positive TIC values contribute to scale. The returned intensities are dimensionless, so intensityunit is nothing. Retention coordinates, m/z values, MS level, metadata, and extras are preserved.

For AbstractVarianceMassScanMatrix, ticnormalize returns a VarianceMassScanMatrix. Variances are propagated by treating the observed TIC sum as a fixed scaling factor:

V_normalized = V ./ scale^2

This deliberately does not propagate uncertainty in scale; doing so would induce covariances between all normalized cells, while VarianceMassScanMatrix stores only per-cell variances. With this fixed-scaling rule, clr(ticnormalize(vmsm)) has the same CLR intensities and propagated CLR variances as clr(vmsm), provided all intensities are strictly positive. If zeros or negative values are present and the result is intended for CLR, call replacecensored before ticnormalize.

Throws ArgumentError if the input has no finite positive TIC sum.

JuChrom.withintensityunit — Function
withintensityunit(msm::MassScanMatrix, unit::Unitful.Units)

Return a copy of msm with the supplied intensity unit attached without changing the stored intensity values.

This function is intended for cases where the numeric intensity values already have a known physical unit, but the matrix currently stores intensityunit(msm) ≡ nothing. It only changes the intensity unit metadata. Retention coordinates, m/z values, intensity values, MS level, and metadata are preserved.

Throws ArgumentError if msm already has an intensity unit.

See also dwellnormalize, intensityunit.

Examples

julia> msm = MassScanMatrix([1.0, 2.0]u"s", [100.0, 200.0], [10.0 20.0; 30.0 40.0]);

julia> annotated = withintensityunit(msm, u"pA");

julia> rawintensities(annotated) == rawintensities(msm)
true

julia> intensityunit(annotated)
pA

withintensityunit(vmsm::VarianceMassScanMatrix, unit::Unitful.Units)

Return a copy of vmsm with the supplied intensity unit attached without changing the stored intensity or variance values.

The parent mass-scan matrix is annotated with unit. The variance matrix is copied unchanged and its unit is set to unit^2, matching the annotated intensity unit.

Throws ArgumentError if vmsm already has an intensity unit or variance unit.

JuChrom.whiten — Function
whiten(vmsm::AbstractVarianceMassScanMatrix; sigmafloor=:auto, floorquantile=0.05)

Whiten a variance mass scan matrix by dividing each intensity by its propagated standard deviation, with a standard-deviation floor.

For each cell, denominator_variance = max(variance, sigmafloor^2). The returned intensity is intensity / sqrt(denominator_variance), and the returned variance is variance / denominator_variance. The returned VarianceMassScanMatrix keeps the retention axis, m/z axis, level, metadata, and extras of the input. Both intensityunit and varianceunit of the returned object are nothing.

By default, sigmafloor = :auto infers a positive floor from the floorquantile quantile of the positive propagated standard deviations. Dimensionless data produce a dimensionless floor. Physical data infer the floor in intensityunit(vmsm).

A bare real sigmafloor is accepted only when varianceunit(vmsm) is nothing or dimensionless, for example after clr. For physical intensity data, pass a unitful floor such as 0.1u"pA"; intensities and variances are converted to that floor unit before units are stripped.

Throws

  • ArgumentError: if sigmafloor <= 0, floorquantile is outside (0, 1], :auto cannot infer a positive floor, or a bare real floor is used for physical variances.
  • DimensionMismatch: if the variance matrix shape does not match the intensity matrix.
