Mass spectra

AbstractMassSpectrum

JuChrom.AbstractMassSpectrum — Type
AbstractMassSpectrum{M, I} <: Any

Abstract supertype for mass spectrum containers holding paired m/z values and intensity values.

M is the m/z unit type (Unitful.Units subtype or Nothing), and I is the intensity unit type (Unitful.Units subtype or Nothing).

Concrete subtypes are expected to define mzvalues::AbstractVector{<:Real}, mzunit::Union{Unitful.Units, Nothing}, intensities::AbstractVector{<:Real}, intensityunit::Union{Unitful.Units, Nothing}, and attrs::NamedTuple.

See also MassSpectrum, attrs, intensities, intensityunit, mzcount, mzunit, mzvalues.

JuChrom.intensities — Method
intensities(ms::AbstractMassSpectrum; unit=nothing)

Return the intensity values from a mass spectrum.

If unit is specified, intensities are converted with Unitful.uconvert. If the spectrum is unitless and a unit is requested, an error is thrown.

See also MassSpectrum, intensityunit, mzcount, mzvalues.

Examples

julia> ms = MassSpectrum([100.0, 150.0], [10.0, 20.0]u"pA");

julia> intensities(ms) == [10.0, 20.0]u"pA"
true

julia> intensities(ms, unit=u"nA") == [0.01, 0.02]u"nA"
true

MassSpectrum

JuChrom.MassSpectrum — Type
MassSpectrum{T1, T2, T3, T4, T5} <: AbstractMassSpectrum{T2, T4}

Concrete container for a single mass spectrum.

T2 and T4 encode the m/z and intensity unit types (each a Unitful.Units subtype or Nothing). The remaining type parameters capture the stored numeric vectors and metadata.

Fields include mzvalues::AbstractVector{<:Real}, mzunit::Union{Unitful.Units, Nothing}, intensities::AbstractVector{<:Real}, intensityunit::Union{Unitful.Units, Nothing}, and attrs::NamedTuple.

The constructor validates that m/z values are strictly increasing, positive, finite, and that intensity values are finite with matching length.

See also AbstractMassSpectrum, MassSpectrum, attrs, intensities, intensityunit, mzcount, mzunit, mzvalues.

Extraction from scans

JuChrom.extractmassspectrum — Function
extractmassspectrum(series::AbstractMassScanSeries, scanindices;
                    subtract=Int[]) -> MassSpectrum
extractmassspectrum(matrix::AbstractMassScanMatrix, scanindices;
                    subtract=Int[]) -> MassSpectrum

Average the supplied scans and subtract the average of the scans in subtract. Match m/z values exactly, treating absent entries as zero, and divide each group's sum by its total number of scans, including scans without that m/z. Floor the final intensities at zero. An empty group contributes zero; at least one group must contain a scan. Each index contributes at most once to each group. An index in both groups contributes to both averages with their respective group weights.

Binning is an explicit preprocessing step: use binmzvalues when nearby m/z values should represent the same channel. No rounding, interpolation, or base-peak normalization is performed here. Compatible units are converted to those of the first contributing scan. Accumulation uses at least Float64 precision.

The result contains the sorted union of contributing m/z values, including zero channels, preserves their numeric type, and records the contributing scan indices in its attributes. Matrices use their shared m/z axis and row indices as scan indices. Variance-bearing matrices are accepted; this operation extracts their intensities without propagating variances into the MassSpectrum. The input is unchanged.

Examples

prepared = binmzvalues(series)
result = extractmassspectrum(prepared, [10, 12, 13]; subtract=[5, 6])

Plotting spectra

Load a Makie backend, such as CairoMakie or GLMakie, to enable spectrum plotting.

JuChrom.massspectrum — Function
massspectrum(mzvalues, intensities; autoylimits=true, show_mz_labels=true, kwargs...)
massspectrum(spectrum::AbstractMassSpectrum; kwargs...)

Plot a stick mass spectrum with Makie. Load a Makie backend to enable this function. Numeric and unitful vectors, and AbstractMassSpectrum containers, are supported.

By default, autoylimits=true fits the Y range to the data with room for mass labels, including after data updates and resizing. Set autoylimits=false to leave Y limits under Makie's ordinary axis controls; for a fixed range, supply axis=(; limits=(nothing, (0, 100))) or use ylims! on the returned axis. show_mz_labels=false skips mass-label placement and its extra headroom, useful for rapidly updated spectra. Both options default to true and can be changed on an existing plot. These options do not normalize or otherwise modify the input data.

Use figure=(; ...) and axis=(; ...) to configure the figure and axis. Plot styles include linecolor, linewidth, intensity_threshold (the label threshold), and the mz_label_* attributes.

source
JuChrom.massspectrum! — Function
massspectrum!(axis, mzvalues, intensities; kwargs...)
massspectrum!(axis, spectrum::AbstractMassSpectrum; kwargs...)

Add a mass spectrum to an existing Makie axis. Supports the plot options of massspectrum, including autoylimits=false to preserve manual Y limits.

To replace numeric m/z and intensity vectors together, including with a different length, use Makie.update!(plot; arg1=new_mzvalues, arg2=new_intensities) on the returned plot. Updating both arguments together avoids an intermediate mismatched pair of vectors.

source

For an interactive view with a fixed intensity range, disable the recipe's automatic Y limits. Labels can also be disabled to avoid their placement work during frequent updates:

using GLMakie, JuChrom
using GLMakie: Makie

fig = Figure()
ax = Axis(fig[1, 1]; limits=(40, 300, 0, 100))
plot = massspectrum!(ax, [50.0, 100.0], [100.0, 20.0];
    autoylimits=false, show_mz_labels=false)

ylims!(ax, 0, 5)
Makie.update!(plot; arg1=[60.0, 90.0, 150.0], arg2=[2.0, 100.0, 1.0])
# The manual 0–5 Y range is retained.
