Format conversion

Conversion tools change representation without changing the underlying data. In JuChrom this means moving between a scan-oriented view (MassScanSeries) and a grid-oriented view (MassScanMatrix), or extracting chromatograms from selected m/z values. These conversions are often useful after preprocessing (for example, m/z binning to a fixed grid) because they make the data shape explicit and unlock workflows that benefit from a matrix representation. Conversion itself does not bin or resample; mzchrom can sum intensities across selected m/z values or tolerances, but it does not merge nearby m/z into new bins. Binning and resampling are handled by m/z binning and retention binning and gridding.

Explicit matrix columns

mscanmatrix requires the output m/z axis as its second argument:

mscanmatrix(series, 29:563)
mscanmatrix(series, (57, 71, 85); unmatched=:drop)
mscanmatrix(series, [57, 71, 85]; format=SPARSE, unmatched=:drop)

The grid may be a vector, range, or tuple, with regular or irregular spacing. It must be nonempty, finite, positive, and strictly increasing; duplicate values are rejected. Every grid value becomes a column, including ions with no recorded intensities. Supplying the same grid across runs fixes their m/z axes independently of which ions were reported. The grid is copied into the result; the input series and grid are not modified.

Matching is exact. Floating-point grids such as 20.1:0.1:200.4 are supported, but recorded values must equal the generated grid values. There is no implicit rounding or tolerance, and 57.1f0 does not equal 57.1. Use binmzvalues beforehand to assign nearby masses to shared values. Its validmzvalues argument only filters bins; it does not add missing columns.

The default unmatched=:error raises an error for any recorded m/z absent from the grid. Use unmatched=:drop for an intentional subset. This check applies only to scans at target_level and happens before intensity filtering, so increasing threshold cannot hide a grid mismatch. Only intensities strictly greater than the threshold are retained. No scans at the selected level is an error; an entirely zero matrix is valid. Dense and sparse storage use the same matching and filtering rules.

For a series with a unitful m/z axis, grids may also contain quantities:

mscanmatrix(unitful_series, (57u"Th", 71u"Th"); unmatched=:drop)
mscanmatrix(unitful_series, [57000, 71000]u"mTh"; unmatched=:drop)
mscanmatrix(unitful_series, (20.1u"Th"):(0.1u"Th"):(200.4u"Th"); unmatched=:drop)

Compatible grid units are converted to the series' m/z unit before exact matching, and that unit is retained in the result. Plain numeric grids use the series' m/z unit, if present. Mixing plain numbers with quantities, using incompatible units, or supplying a unitful grid for a unitless series is an error. Retention and intensity units and series metadata are preserved as well.

Zero filling is a representation choice: it does not distinguish an unacquired ion from an acquired ion omitted by the instrument. An explicit matrix grid does not by itself establish acquisition coverage or dwell times.

Example

# Load JuChrom and the Agilent ChemStation MS loader
using JuChrom
using JuChrom.ChemStationMSLoader

# Load an example Agilent ChemStation GC-MS run
file = joinpath(JuChrom.agilent, "C7-C40_ChemStationMS.D", "data.ms")
mss = load(ChemStationMS(file; mode=:ms))

# Extract a chromatogram of the target m/z with tolerance on raw m/z values
xic_104_tol = mzchrom(mss, 104.0; tol=1e-2)

# Integer-bin m/z values to a fixed grid
mss_binned = binmzvalues(mss)

# Extract a chromatogram of the target m/z on the binned grid
xic_104 = mzchrom(mss_binned, 104)

# Extract a summed chromatogram across multiple target m/z
xic_43_57_71_85 = mzchrom(mss_binned, [43, 57, 71, 85])  # or 43:14:85

# Extract total ion chromatogram (across all ions)
tic = mzchrom(mss_binned)

# Convert the binned series to a matrix for matrix-based workflows
msm = mscanmatrix(mss_binned, 29:563)  # nominal grid from the example acquisition method

Conversion tools

JuChrom.mscanmatrix — Function
mscanmatrix(series::MassScanSeries, mzgrid;
            format=DENSE, target_level::Integer=1, threshold::Real=0.0,
            unmatched::Symbol=:error) -> MassScanMatrix

Convert scans at target_level to a retention × m/z matrix on the explicit mzgrid.

mzgrid must be a nonempty vector, range, or tuple of finite, positive, strictly increasing m/z values. Spacing may be arbitrary. Every requested value gets a column, including values absent from every scan. The grid is copied, never inferred from the recorded ions, sorted, or deduplicated. Use format=DENSE (the default) or format=SPARSE to choose storage.

Matching is exact, with no rounding, binning, or tolerance. For example, 57.1f0 and 57.1 do not match. Apply binmzvalues beforehand when needed. With unmatched=:error, any recorded m/z absent from the grid raises ArgumentError. Use unmatched=:drop to deliberately select a subset. Only scans at target_level are checked, but all their m/z values are checked before intensity filtering. Only intensities strictly greater than threshold are retained.

Grid entries must be either all plain real numbers or all real-valued Unitful quantities. Plain values are interpreted in the series' m/z unit, if any. Unitful values are converted to that unit before exact matching; compatible units may differ between entries. A unitful grid requires a unitful series. Mixed plain/unitful values and incompatible units raise ArgumentError. The result preserves the series' m/z, retention, and intensity units, numeric intensity type, and metadata.

An absent entry is represented by zero; this does not establish whether the ion was acquired or whether its signal was suppressed during acquisition. An entirely zero matrix is valid. No scans at the requested MS level raises ArgumentError.

Examples

julia> series = MassScanSeries([
           MassScan(1.0u"s", [57, 71], [10, 20]),
           MassScan(2.0u"s", [57, 85], [5, 30])]);

julia> matrix = mscanmatrix(series, 57:14:99);

julia> rawmzvalues(matrix)
4-element Vector{Int64}:
 57
 71
 85
 99

julia> rawintensities(matrix) == [10 20 0 0; 5 0 30 0]
true

julia> sparsematrix = mscanmatrix(series, (57, 71, 85, 99); format=SPARSE);

julia> rawintensities(sparsematrix) isa SparseMatrixCSC
true

julia> rawintensities(sparsematrix) == rawintensities(matrix)
true

julia> selected = mscanmatrix(series, (57, 71); unmatched=:drop, threshold=5);

julia> rawintensities(selected) == [10 20; 0 0]
true

julia> unitful = MassScanSeries([MassScan(1u"s", [57, 71]u"Th", [10, 20]u"pA")]);

julia> converted = mscanmatrix(unitful, (57000u"mTh", 71000u"mTh", 85000u"mTh"));

julia> mzvalues(converted) == [57, 71, 85]u"Th"
true

julia> intensities(converted) == [10 20 0]u"pA"
true

JuChrom.mzchrom — Function
mzchrom(series::MassScanSeries,
        selection::Union{Nothing, <:Number, AbstractVector{<:Number}}=nothing;
        tol::Number=3e-4,
        warning::Bool=true)

Extract a chromatogram scan series from a MassScanSeries.

If selection is nothing (default), the Total Ion Current (TIC) is returned. If selection is a scalar or a collection of m/z targets or column indices, an extracted ion chromatogram (XIC) is returned. In case of a collection, intensities of the selected m/z values or column indices are summed per scan. Whether the targets in selection are interpreted as m/z values (:mz, default) or column indices (:index) is controlled by the by keyword argument. tol is the absolute tolerance used when matching m/z selections to the discrete m/z grid; the nearest m/z within tol is chosen per target. tol may be numeric or unitful. If the matrix m/z values are unitless, tol must be unitless; if the m/z values carry a unit, numeric tol is interpreted in that unit and unitful tol is converted to the m/z unit, with incompatible units raising an error. warning controls whether missing matches or out-of-bounds indices emit warnings.

Returns a ChromScanSeries with retention time and intensity units preserved.

See also ChromScanSeries, MassScanSeries, uniquemzvalues.

source

Extract a chromatogram scan series from a MassScanMatrix.

This method follows the same TIC/XIC behavior and unit handling as mzchrom(series::MassScanSeries, ...). The additional by keyword controls whether selection targets m/z values (:mz, default) or column indices (:index) in the matrix.

Returns a ChromScanSeries with retention time and intensity units preserved.

See also ChromScanSeries, MassScanMatrix, mzvalues, mzcount, rawmzvalues.
